    What is real here

    The request parser, ranking, order flow, payment protection, handover code check, photo fingerprinting, receipts and payouts are the production code. Every log line is read back from the rows and messages that code just wrote.

    What is simulated

    WhatsApp is a recording line that shows replies on this phone instead of sending them. Payments go to a sandbox provider. The five shops and their owners are sample data with reserved numbers.

    Meta models

    With a Meta API key, Muse Spark reads requests and photos and SAM 3.1 finds the product in the delivery photo; voice notes are made with MMS-TTS. Without a key the log says so and the rules fallback runs, as it would in production.
