# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting for this repository:
https://github.com/tito-devsec/moranbuy/security/advisories/new

If that page is unavailable, send a GitHub direct message to the repository owner `tito-devsec`
asking for a private channel, with no details of the vulnerability in the first message.

Include the affected area (customer, business, admin, API, workers), steps to reproduce, and the
impact you believe it has. Do not include customer data, credentials or production records.

## What to expect

- Acknowledgement within 5 working days.
- A fix or mitigation plan before any public disclosure.
- Credit in the changelog if you want it.

## Scope

This repository (`moranbuy`). Problems in the Moran AI platform itself belong to that project's owner.

## Supported versions

The `main` branch and the latest tagged release.
