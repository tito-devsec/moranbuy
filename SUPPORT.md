# Support

- **Bugs**: open an issue with the Bug report template. Include the version, the experience affected (customer, business, admin), steps, expected and actual behaviour, and redacted logs. Never paste secrets, phone numbers or customer data.
- **Feature requests**: use the Feature request template.
- **Security problems**: follow `SECURITY.md`; do not open a public issue.
- **Setup help**: read `CONTRIBUTING.md`, `docs/deployment.md` and `docs/testing.md` first, then open an issue tagged `question`.

Response times are best effort; this is a small team.
